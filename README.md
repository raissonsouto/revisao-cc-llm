# Revisão bibliográfica — POI (PPGCC/UFCG)

Provisionamento e operação de infraestrutura para computação confidencial
aplicada a LLMs. Artigo no template SBC. Prazo: 01/12/2026.

## Compilar

```sh
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Estrutura

- `main.tex`: artigo
- `references.bib`: referências (entradas `[VERIFICAR]` pendentes)
- `notas/fichas.md`: fichas de leitura
- `sbc-template.sty`, `sbc.bst`: template oficial da SBC
